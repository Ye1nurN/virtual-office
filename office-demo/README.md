# Наш офис

Основная и единственная версия приложения — интерактивный четырёхэтажный 3D-офис: http://127.0.0.1:4173/. Старые ссылки с `?view=3d` открывают тот же офис. Демо на основе фонового изображения удалено.

Сцена собрана из GLB-моделей: доступны ходьба, двери, посадка, лифт, карточки людей и отделов. Устройство этажей и замена моделей описаны в [WORLD.md](WORLD.md). Каталог из 87 отдельных моделей: http://127.0.0.1:4173/models.html; исходники и ограничения — в [asset-library/README.md](asset-library/README.md).

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

На текущем компьютере `./start-demo.ps1` использует Node.js из среды Codex. Сервер слушает локальный интерфейс.

## Управление

- WASD / ЦФЫВ или стрелки — ходить относительно экрана; Shift — быстрее.
- E — дверь, посадка, лифт; клик по свободному полу — пройти к точке.
- Home или прицел — вернуть камеру; колесо и кнопки +/− — масштаб.
- Меню «Наш офис» — переход между четырьмя этажами.
- Клик по коллеге/отделу — профиль, задачи и назначение отдела.
- `/` — поиск; Escape — остановиться и закрыть панель.
- «Команда», «Развитие», локальный чат и статусы — интерактивные демонстрационные сценарии.

Клавиши распознаются по физической позиции, затем по букве, включая D/В при нестандартном или переназначенном коде. Числовой код используется только при отсутствии осмысленного значения буквы. Нажатие и отпускание отслеживаются вместе. Ввод в поля, открытые панели и сочетания Ctrl/Alt/Meta не двигают персонажа.

Для проверки повторяющегося сбоя D/В откройте офис с `?keyboard=1`, нажмите «Начать проверку», затем D/В и стрелку →. Кнопка «Скопировать результат» возвращает события клавиатуры, причину обработки и координаты движения. Отчёт хранится только в текущей вкладке, не включает текст из полей и никуда автоматически не отправляется. Без параметра панель не создаётся. Причина сбоя в браузере пользователя пока не установлена.

## Устройство и проверка

- `src/App.jsx` — интерфейс, данные четырёх этажей, локальные панели.
- `src/world/` — конфигурация этажей, GLB, камера, взаимодействия и отрисовка.
- `src/movement.js` — клавиатура, столкновения и поиск пути.
- `src/reference-ui.css` — оформление интерфейса по референсу; не альтернативная версия приложения.
- `public/assets/approved-design.png` — художественный референс и источник аватара; не фон приложения.

В покое новые кадры не рисуются; фоновые вкладки останавливают цикл. Повторяемая мебель использует instancing, модели и материалы кешируются. Данные вымышлены, сбрасываются при обновлении; серверной синхронизации и настоящих звонков пока нет.

```sh
npm test
npm run test:sites
npm run build
```

Сборка создаёт `dist/client`, `dist/server/index.js` и `dist/.openai/hosting.json`. React 19, Vite 6, Three.js.
