# Наш офис

Локальное кликабельное демо на основе изображения, выбранного пользователем. Стартовый экран использует оригинал 1280 × 910 без перерисовки: сохранены сцена, дневное освещение, мебель, персонажи и интерфейс. Кнопки, поля и панели работают поверх изображения. Это согласованный визуальный макет, без свободного 3D-перемещения.

Интерактивный четырёхэтажный 3D-офис: http://127.0.0.1:4173/?view=3d. Сцена собрана из предоставленной библиотеки GLB, с ходьбой, дверями, посадкой, лифтом и работающим UI. Управление, устройство и замена моделей — в [WORLD.md](WORLD.md). Это самостоятельная сцена по четырёхэтажной планировке; она не является попиксельной копией иллюстрации.

Отдельная библиотека новых 3D-реконструкций: http://127.0.0.1:4173/models.html. Доступны 87 GLB-объектов (включая резерв), просмотр со всех сторон, примеры сборки и редактируемый Blender-исходник. Состав, оси и ограничения — в `asset-library/README.md`. Это первая реконструкция по одному ракурсу, а не точные оригинальные модели из изображения.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

Открыть http://127.0.0.1:4173. На текущем компьютере также можно запустить `./start-demo.ps1`, который использует установленный Node.js из среды Codex. Сервер слушает только локальный интерфейс.

```sh
npm run build
```

## Что можно попробовать

- Клик по персонажу или названию отдела: профиль, задача, назначение отдела и список коллег.
- Кнопки масштаба: 100%, затем 130–180%. При увеличении изображение можно перетаскивать; кнопка прицела возвращает полный вид. Это приближение изображения, а не движение 3D-камеры.
- Поиск по людям и отделам, клавиша `/`, закрытие панелей по Escape.
- «Команда»: список, фильтр доступности, переход к отделам.
- «Развитие»: требования к уровню, добавление примера наставничества, форма запроса и состояние отправки.
- Локальный чат, смена статуса, уведомления, демонстрационные состояния звонка и медиакнопок.

## Границы демо

Все данные вымышлены. Состояние живёт в памяти браузера и сбрасывается при обновлении. Нет серверной синхронизации, авторизации, разделения компаний, реальных сообщений, камеры, микрофона или видеозвонков. Кнопки медиа показывают состояния интерфейса и не запрашивают доступ к устройствам. Запросы повышения не уходят людям.

Изображение сохраняет пропорции и целиком помещается в окно. При другом соотношении сторон остаются нейтральные поля. Макет рассчитан прежде всего на настольный экран: на узком экране весь офис уменьшается, а открытые панели занимают доступную высоту. В исходнике нет изображений открытых панелей, поэтому они используют существующую светлую систему интерфейса проекта.

В отдельном режиме `?view=3d` доступны клик по полу с обходом мебели, WASD/стрелки, Shift, Home и движение камеры. Сохранены поддержка русской раскладки, блокировка движения при вводе текста и оптимизация отрисовки.

## Устройство

- `src/ReferenceOffice.jsx` — основной макет, семантические области выбора, масштабирование изображения.
- `src/reference-demo.css` — точное масштабирование композиции, интерактивные состояния и адаптация панелей.
- `public/assets/approved-design.png` — неизменённый оригинал пользователя, источник стартового экрана и аватара.
- `src/world/` — четырёхэтажный режим Three.js: конфигурация, библиотека GLB, взаимодействия и отрисовка по необходимости.
- `src/officeScene.js` — сохранённый исходник прежней процедурной сцены.
- `src/movement.js` — клавиатурный ввод, столкновения, пространственный индекс и A* с очередью приоритетов.
- `src/rendering.js` — объединение геометрии персонажей и освобождение ресурсов.
- `src/App.jsx` — интерактивный интерфейс и локальное состояние.
- `src/office.css` — плавающие панели и адаптивная вёрстка.
- `src/data.js` — демонстрационные сотрудники и отделы.
- `public/assets` — созданные изображения и текстуры; описание в `ASSETS.md`.
- `qa` и `design-qa.md` — браузерные снимки и результаты проверки.

React 19, Vite 6, Three.js, Inter Variable, Phosphor Icons. Источники библиотек: [Three.js](https://threejs.org/), [Phosphor React](https://github.com/phosphor-icons/react), [Inter](https://rsms.me/inter/).

## Оптимизация и проверка

В основном режиме Three.js и WebGL не загружаются. В отдельном 3D-режиме в покое новые кадры не рисуются. При движении работают анимация ног и обновление теней; после остановки карта теней используется повторно. Фоновая вкладка останавливает цикл и сбрасывает клавиши. Статические экземпляры GLB объединяются через instancing; материалы и подвижные узлы персонажей сохраняются. Движок загружается отдельным JS-модулем. Изображения прежнего демо переведены в WebP без потерь; новый утверждённый исходник сохранён в PNG без изменений.

```sh
npm test
```

Тесты проверяют коллизии, маршруты, диагональную скорость, русскую раскладку, резервную обработку D/В, ввод текста, потерю фокуса, очистку ресурсов, каталог моделей, прямой вход к ресепшену, двери, точки появления и места посадки всех четырёх этажей. Отдельно проверяются слежение камеры, направления движения относительно экрана и границы архитектурных моделей. Замеры — в `qa/world/metrics.json` и `qa/world-follow/`, браузерные проверки — в `design-qa.md`; прежние замеры сохранены в `qa/optimization.md`.
