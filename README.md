# Виртуальный офис

Браузерный офис компании: четыре этажа, персонаж с управлением WASD, двери, лифт, карточки сотрудников и отделов. Проект также содержит исходное кликабельное демо, каталог из 87 GLB-моделей и редактируемую библиотеку Blender.

Исходники приложения находятся в [`office-demo/`](office-demo/).

## Запуск

Требуется Node.js 22.12 или новее.

```sh
cd office-demo
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

- Интерактивный 3D-офис: http://127.0.0.1:4173/?view=3d
- Исходное демо: http://127.0.0.1:4173/
- Каталог моделей: http://127.0.0.1:4173/models.html

```sh
npm test
npm run test:sites
npm run build
```
