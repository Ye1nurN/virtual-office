# Остров

Компактный музыкальный плеер для Windows. Нативное приложение WPF / .NET Framework, без браузера, сервера и подписки. Панель и её меню используют тёмную тему.

## Запуск

Запустите `bin\Release\Ostrov.exe` после сборки. Для работы нужна Windows 10 1809 или новее и .NET Framework 4.7.2 или новее.

- `Alt+M` открывает и скрывает панель. Если сочетание занято, приложение пробует `Ctrl+Alt+M`.
- `Esc`, кнопка закрытия и клик вне панели скрывают её. Воспроизведение продолжается.
- Повторный запуск EXE открывает уже работающий экземпляр. В трее доступны открытие, импорт музыки и выход.
- Невидимую область активации в центре верхнего края можно отключить через меню в трее. В полноэкранных приложениях она скрывается.
- Автозапуск не включается автоматически.

## Источники

В меню сверху доступны три режима:

- **Сейчас играет** — текущая играющая медиасессия Windows; при нескольких играющих источниках предпочтение получает текущий источник Windows.
- **Только Telegram Desktop** — управление обнаруженной медиасессией Telegram.
- **Моя музыка** — файлы, добавленные пользователем через выбор файлов, папки или перетаскивание. Приложение запоминает пути, не копирует и не изменяет исходники.

Названия, обложки и доступные команды внешних источников зависят от приложения. Если источник не передаёт время трека, шкала скрывается без дополнительной надписи. Проверенная версия Telegram Desktop 7.2.9 передаёт название и состояние, но не длительность, позицию или перемотку. Громкость и очередь внешнего источника регулируются в самом приложении. Отдельного выбора вкладок браузера пока нет.

Остров не читает переписку, `tdata` и данные входа в Telegram, не скачивает музыку и не делает сетевых запросов. Метаданные внешних источников не сохраняются в библиотеку.

Локальная библиотека поддерживает MP3, WAV, M4A, WMA, AAC и FLAC; доступность декодера зависит от Windows. «Похожее» подбирает треки из добавленной коллекции по тегам, избранному и истории прослушивания; это не внешний музыкальный каталог.

## Данные и нагрузка

Настройки и пути к локальным файлам хранятся в `%LOCALAPPDATA%\Ostrov\library.json`, резервная копия — `library.bak`.

Скрытая панель не запускает таймер обновления прогресса. Подключение к внешним источникам получает события Windows; обложка загружается для открытой панели. Декодирование локального аудио продолжает использовать ресурсы во время воспроизведения.

## Сборка и проверка

Нужны MSBuild из Visual Studio Build Tools 2022, reference assemblies .NET Framework 4.7.2 и Windows SDK 10.0.22621.0. Версию установленного SDK можно переопределить свойством MSBuild `WindowsSdkVersion`.

```powershell
.\build.ps1 -Test
```

Перед сборкой завершите работающий Остров через меню в трее, чтобы освободить EXE и горячую клавишу. Проверки используют временный профиль и тихий WAV в игнорируемой папке `.qa`.

Диагностика: `Ostrov.exe --media-probe <путь-к-отчёту>` записывает текущие медиасессии, названия треков и параметры времени. Такой отчёт содержит данные о прослушивании, его не следует коммитить. `--data-dir <папка>` позволяет использовать отдельный профиль для проверки.

В Git сохраняются только исходники; `bin`, `obj` и `.qa` исключены. Браузерный черновик из соседнего каталога `music-island-prototype` приложению не нужен.
