# Гид по городу

Персонаж у площади, единый текстовый разговор, факты о проектах, действия по нажатию и короткая экскурсия «Аптека → ARGUS → офис». История живёт только в памяти текущей вкладки и сохраняется при переходах между зданиями. Перезагрузка и «Новый разговор» её очищают. По просьбе показать дорогу **идёт сам гид**, обходя препятствия. Посетитель сам решает, следовать ли за ним, и управляет своим персонажем; камера остаётся у посетителя. Гид движется немного медленнее обычного шага игрока и ждёт сбоку от входа, оставляя дверь свободной. Голос не реализован.

## Запуск

Обычные `npm run dev`, `npm test`, `npm run build`. Кнопка «Гид по городу» доступна на всех экранах; в 3D можно подойти к гиду и нажать E / У или его подпись. Диалог блокирует движение посетителя и останавливает гида для разговора, Escape закрывает его. Отправка — Enter, перенос — Shift+Enter. «Остановить гида», «Продолжить путь гида» и отмена управляют только NPC; WASD и клик по дорожке его не останавливают. В карточке экскурсии «Войти» появляется, когда гид пришёл и посетитель сам подошёл к двери; E у входа также доступна. При выборе следующего проекта из интерьера посетитель остаётся внутри: гид продолжит путь после самостоятельного возвращения в город. Позиция NPC сохраняется между сценами в пределах вкладки.

## Два явных режима

- Без серверного подключения: готовые ответы и экскурсии. Это не свободный AI-диалог. Для неизвестного вопроса гид объясняет ограничение.
- При заполненных `OPENAI_API_KEY` и `GUIDE_MODEL`: свободный разговор через OpenAI Responses API. Модель получает утверждённые описания проектов, текущую локацию, выбранный проект и до 12 последних реплик. Модель нужно выбрать в своём API-проекте с поддержкой Responses / Structured Outputs; приложение не подставляет платную модель автоматически.

Для локального запуска скопируйте `.env.example` в `.env.local`, заполните **на своей машине**, перезапустите Vite. Не используйте `VITE_` для ключа. `.env.local` игнорируется Git. Значения секретов не выводятся в интерфейс или журнал. Никаких изменений аккаунта или платных запросов при отсутствии ключа не происходит.

## Cloudflare Pages

Существующая сборка остаётся `npm run build`, корень `city-demo`, результат `dist/client`. Git-сборка Pages подхватывает `functions/api/guide.js`: маршрут `/api/guide` вызывает серверный обработчик. В Settings → Variables and Secrets добавьте **секрет** `OPENAI_API_KEY` и переменную `GUIDE_MODEL` для нужного окружения, затем повторите развёртывание. Успешная сборка статических файлов сама по себе не проверяет ответ платной модели. Проверяйте сначала `GET /api/guide` (mode: ai), затем реальный вопрос. Обычный статический хостинг без Functions сохраняет локальные ответы; загрузка только `dist/client` не переносит исходник Functions автоматически.

Сервер ограничивает размер тела, длину сообщения/истории, время ожидания и объём ответа. Есть базовый лимит 12 AI-запросов в минуту на IP в одном экземпляре обработчика. Он **не является глобальным лимитом расходов**: для публичного AI включите ограничения и бюджет на стороне провайдера/edge. В приложение не включены аккаунты посетителей, постоянная память, аналитика разговоров или голос.

## Устройство

- `src/guide/knowledge.js`: подтверждённые сведения, локальные ответы, разрешённые действия. Данные зданий берутся из существующего каталога. Для более полных ответов добавляйте реальный вклад автора, решения и ограничения.
- `guideStore.js`: разговор, переходы экскурсии и сохранение позиции NPC; изолирован от React и 3D.
- `guideWalker.js`: собственный путь NPC по общей сетке препятствий, скорость и остановка у входа; не управляет посетителем.
- `GuideOverlay.jsx`, `guide.css`: адаптивный диалог, доступная клавиатурная навигация, действия и статус маршрута.
- `guideActor.js`: персонаж из имеющейся GLB с рюкзаком, значком и анимацией шага. Метка и зона разговора перемещаются вместе с ним.
- `server/guideHandler.mjs`: проверка запроса, база знаний, Responses API, фильтрация действий/источников.
- `server/guidePlugin.mjs`: тот же обработчик для Vite dev/preview; `functions/api/guide.js` — для Pages.

Модель не управляет сценой напрямую. Она предлагает только `project`, `walk`, `enter`, `about`, `tour` с известными ID. Кнопки валидируются повторно в браузере; произвольные URL, скрипты и названия действий от модели не исполняются. Текст выводится средствами React без HTML. Ссылки берутся из локального каталога, а не из ответа модели.

Документация: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [Pages Functions routing](https://developers.cloudflare.com/pages/functions/routing/), [Pages secrets](https://developers.cloudflare.com/pages/functions/bindings/).
